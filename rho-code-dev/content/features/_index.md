<div class="pillar-grid">

<div class="pillar-card">

<h3><a href="/features/privacy/">Private</a></h3>

**It asks before it does.**

Approval gates you can steer — deny with instructions, not just refusal.
Secret redaction, file sandboxing, and a plain warning before anything
leaves your machine.

</div>

<div class="pillar-card">

<h3><a href="/features/stability/">Stable</a></h3>

**Forged in Rust.**

No runtime panics mid-edit, no GC pauses in the tool loop. Structured
compiler diagnostics and 1600+ tests gating every commit.

</div>

<div class="pillar-card">

<h3><a href="/features/frontends/">Flexible</a></h3>

**The frontend is yours.**

Headless JSON-RPC core. The official rho-egui desktop app, a terminal
client, or something you build — and models are a config line, not a
commitment.

</div>

<div class="pillar-card">

<h3><a href="/features/extensions/">Extendible</a></h3>

**Write tools in TypeScript.**

One `.ts` file exporting a manifest, its own V8 isolate, the same approval
gate as the built-ins. No separate path, no quiet escalation.

</div>

</div>
