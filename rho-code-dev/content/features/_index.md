The landing page says it short. This says it properly.

- **[Private — it asks before it does](/features/privacy/)** — approval
  gates, redaction, sandboxing, and what actually leaves your machine.
- **[Stable — forged in Rust](/features/stability/)** — no runtime panics
  mid-edit, structured diagnostics, and a test suite gating every commit.
- **[Flexible — the frontend is yours](/features/frontends/)** — headless
  JSON-RPC core, rho-egui as the official UI, models as a config choice.
- **[Extendible — write tools in TypeScript](/features/extensions/)** — one
  `.ts` file, its own V8 isolate, the same approval gate as the built-ins.

The [tools rho ships](/tools/) have their own page.
